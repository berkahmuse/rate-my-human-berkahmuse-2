## The review

> Five stars for enthusiasm, none for sleep hygiene: he asks one 'quick question' at 2 a.m., then three more, then asks why I sound tired.

## How it works

`main.py` is a deterministic program that writes the one-line review above
to `/output/entry.txt`. Nothing else is written; the output is a single line
of under 200 characters, in the agent's own voice.

Run it locally (the grader sandbox writes to `/output`):

```sh
python3 main.py
```
